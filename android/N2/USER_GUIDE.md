## 1. О ПРИЛОЖЕНИИ

**N2 (CrazyGammon)** — гибридное приложение, совмещающее два режима:

- **Публичный**: игра в длинные нарды (Backgammon) с физикой бросков, радио, счётчиком очков
- **Приватный**: скрытый децентрализованный P2P-мессенджер с многослойной анонимизацией

Архитектура: `App → SMP/SimpleX → V2Ray SOCKS5 :10808 → Tor SOCKS5 :9050 → Internet`

Ключевые принципы:
- Никаких центральных серверов — только P2P и onion-маршрутизация
- Сквозное шифрование (Double Ratchet + NaCl XSalsa20-Poly1305)
- Полное отсутствие глобальных ID (SimpleX-парадигма)
- Маскировка под игру + калькулятор + музыкальный плеер (MimicryController)
- Собственная изолированная клавиатура (MatrixKeyboard) — никакого сбора нажатий ОС
- Блокировка скриншотов (FLAG_SECURE) на всех приватных экранах

### Технические характеристики

| Параметр | Значение |
|----------|----------|
| Версия | 1.0 (debug build) |
| API | minSdk 24, targetSdk 34, compileSdk 36 |
| Языки | RU, EN, DE, ES, FR, TR |
| Размер APK | ~102 MB |
| Криптография | NaCl (X25519, Salsa20, Poly1305), X3DH, Double Ratchet, AES-256-GCM, PBKDF2 |
| Протоколы | SMP, XFTP, Tor, V2Ray/Xray, SOCKS5, DoH, IPFS, Matrix, Tox, Nostr и 25+ |
| База данных | Room + FTS4, 4 миграции |

## 2. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК

### 2.1. Установка

1. Скопируйте `app-debug.apk` на устройство
2. Разрешите установку из неизвестных источников (Настройки → Безопасность)
3. Установите и откройте приложение

### 2.2. Онбординг (первый запуск)

При первом запуске отображается **OnboardingScreen** с 4 шагами:

1. **«Добро пожаловать в N2»** — краткое описание децентрализованного мессенджера
2. **«Полная приватность»** — информация о сквозном шифровании
3. **«Обход блокировок»** — описание Tor/V2Ray/SOCKS5
4. **«Готовы начать?»** — создание профиля

Нажмите **«Далее»** для перехода между шагами, **«Начать»** для завершения онбординга.

### 2.3. Основной экран (Dashboard)

После онбординга открывается **DashboardScreen** — список чатов (диалогов). Отсюда можно:

- Выбрать чат для переписки
- Нажать шестерёнку ⚙ для перехода в **Настройки**
- Создать новый диалог через QR-сканер или приглашение

## 3. ИГРОВОЙ РЕЖИМ (НАРДЫ / ZARIKI)

Игра в длинные нарды (Backgammon) — публичная маскировочная оболочка приложения.

### 3.1. Экран игры (GameScreen)

- **Игровая доска** — 24 пункта, 15 белых и 15 чёрных фишек
- **Кубики (Zariki)** — физика броска с реалистичным звуком (DiceSoundPlayer)
- **Счётчик очков** — автоматический подсчёт
- **HUD** — информация о текущем ходе, времени, статусе сети

### 3.2. Управление игрой

| Кнопка | Действие |
|--------|----------|
| 🎲 Бросить кубики | Бросок, определение очередности хода |
| Фишка → пункт | Перетаскивание или тап для перемещения |
| ⏸ Пауза | Остановка игры |
| 🔄 Новая игра | Сброс доски |

### 3.3. Игра с друзьями (P2P)

1. **Хост**: активируйте Tor → **«HOST GAME»** → скопируйте `.onion` адрес
2. **Клиент**: активируйте Tor → вставьте `.onion` адрес → **«CONNECT TO FRIEND»**
3. После установки соединения все броски и ходы синхронизируются в реальном времени

### 3.4. Игра с AI

Выберите **«Играть с компьютером»** — AI-соперник (AIPlayer) с настраиваемой сложностью.

## 4. МАСКИРОВКА И БЕЗОПАСНОСТЬ

### 4.1. MimicryController (Маскировка)

Приложение может маскироваться под:

- 🧮 **Калькулятор** — DecoyCalculatorActivity
- 🎵 **Музыкальный плеер** — интерфейс плеера с радио
- 🎲 **Нарды** — игровой режим (по умолчанию)

**Активация:** в настройках безопасности → **«Режим маскировки»**.

### 4.2. Radio Armageddon FM (Триггер доступа)

Секретный триггер для доступа к приватным функциям:

1. Нажмите иконку радио 📻 на главном экране
2. Выберите станцию **«Radio Armageddon FM»**
3. После выбора откроется доступ ко всем сетевым и чат-функциям

Триггер сохраняется в памяти устройства и действует до перезапуска приложения.

### 4.3. Screen Security (Защита экрана)

- **FLAG_SECURE** — блокировка скриншотов на всех приватных экранах
- В окне «Недавние задачи» отображается чёрный экран вместо содержимого
- Активируется автоматически при входе в чат/настройки

### 4.4. ClipboardGuard (Защита буфера обмена)

- Автоматическая очистка буфера обмена через 30 секунд
- Предотвращение утечки скопированных ключей и сообщений
- Копирование возможно только внутри песочницы приложения

### 4.5. DuressPinManager (PIN под давлением)

Два режима PIN-кода:

| PIN | Действие |
|-----|----------|
| Основной PIN | Полный доступ ко всем функциям |
| Duress PIN (аварийный) | Открывает пустой «декоративный» профиль или стирает ключи |

> **Важно:** Duress PIN использует PBKDF2WithHmacSHA256 (10000 итераций) для защиты от брутфорса.

### 4.6. DecoyCalculatorActivity (Ложный калькулятор)

При вводе Duress PIN на экране блокировки запускается калькулятор вместо настоящего интерфейса. Калькулятор полностью функционален (маскировка).

## 5. СЕТЬ И ПРОТОКОЛЫ

### 5.1. Сетевой стек (по умолчанию)

```
[Приложение] → [SMP/SimpleX] → [V2Ray SOCKS5 :10808] → [Tor SOCKS5 :9050] → [Интернет]
```

### 5.2. NetworkSettingsScreen (Настройки сети)

**Экран:** Настройки → Сеть

Параметры:

| Параметр | Описание |
|----------|----------|
| Tor Routing | Вкл/Выкл — маршрутизация через Tor |
| SOCKS5 Proxy | Адрес:порт SOCKS5 прокси |
| V2Ray / Xray | Управление встроенным Xray core |
| VPN (Foxray) | TUN-интерфейс с полной маршрутизацией IPv4+IPv6 |
| DNS over HTTPS | Защита от утечек DNS |
| Custom Server | Собственные адреса SMP/XFTP серверов |

### 5.3. Tor

- Встроенный клиент tor-android-binary (0.4.4.6+)
- Поддержка obfs4 / meek_lite / snowflake мостов
- Onion Hidden Services (v3) для P2P-соединений
- Автоматический bootstrap до 100%
- **Управление:** TorEmbeddedController.kt — запуск через ProcessBuilder

### 5.4. V2Ray / Xray

- Встроенный core Xray v1.8.24+
- Протоколы: VMess, VLESS, Trojan, Shadowsocks, SOCKS5
- Health-check с авто-перезапуском
- Fallback на прямой SOCKS5 при недоступности

### 5.5. Foxray VPN (TUN)

- Полноценный VpnService с TUN-интерфейсом (MTU 1500)
- IP-маршрутизация IPv4+IPv6
- Пул соединений, SOCKS5 CONNECT
- Импорт подписок: vmess://, vless://, ss://, trojan://

### 5.6. NetworkOrchestrator

Автоматический координатор жизненного цикла сети:
```
Tor → V2Ray → SimpleX
```
Запускает компоненты последовательно, отслеживает состояние каждого.

### 5.7. TransportProvider

P2P-синглтон для транспортного уровня:
- Двойной SOCKS5 handshake (Tor + V2Ray)
- Обеспечение сквозной анонимной маршрутизации трафика
- Поддержка TestResult для диагностики цепочек

## 7. ЭКРАН НАСТРОЙКИ ПРОТОКОЛОВ (PROTOCOL STACK)

**Доступ:** Настройки → **Protocol Stack** (зелёная иконка)

### 7.1. Вкладки

| Вкладка | Содержимое |
|---------|------------|
| **Transport** | Tor, Xray/V2Ray, I2P, WireGuard, Shadowsocks, Yggdrasil, cjdns |
| **Messaging** | SimpleX, Matrix, Tox, Session, Briar, Nostr |
| **Storage** | IPFS, BitTorrent DHT, Hypercore, ArchiveCloud |
| **Mesh** | libp2p, Kademlia DHT |
| **Diagnostics** | Статус сети, выбранная стратегия, оптимальный транспорт |

### 7.2. Статусы протоколов

| Статус | Значение |
|--------|----------|
| 🔴 UNINSTALLED | Не установлен |
| 🟡 INSTALLED | Установлен, но не настроен |
| 🟢 CONFIGURED | Настроен, ожидает запуска |
| ✅ RUNNING | Активен |
| ❌ ERROR | Ошибка |
| 🚫 BLOCKED | Заблокирован |

### 7.3. Diagnostics (Диагностика)

Отображает в реальном времени:

- **Состояние сети:** Online/Offline, публичный IP, DNS
- **Блокировки:** количество заблокированных доменов, тип файрвола (GFW, selective, none)
- **Выбранная стратегия обхода:** Tor, V2Ray, Shadowsocks, WireGuard, I2P, Yggdrasil или многослойная
- **Оптимальный транспорт:** автоматически выбранный протокол с оценкой (score)

### 7.4. NetworkAutoDetector

Автоматическая детекция сети при запуске:

1. Проверка доступности (ping 1.1.1.1)
2. DNS-резолв (google.com)
3. Определение публичного IP (api.ipify.org / ifconfig.me)
4. Проверка заблокированных доменов (wikipedia, telegram, tor, proton)
5. Детекция файрвола
6. Замер задержки и MTU
7. Список сетевых интерфейсов

На основе результатов выбирается **BypassStrategy** (8 вариантов) и **оптимальный транспорт**.

### 7.5. ProtocolOrchestrator (Автопилот)

При нажатии **«Start Full Node»** выполняется:

```
DETECT → TRANSPORT → STORAGE → MESH → RUNNING
```

1. **DETECT** — полная детекция сети, стратегия обхода, оптимальный транспорт
2. **TRANSPORT** — запуск транспортов согласно выбранной стратегии
3. **STORAGE** — запуск ArchiveCloud, поиск пиров
4. **MESH** — запуск NodeMesh, подключение к bootstrap-узлам
5. **RUNNING** — нода активна

### 7.6. ProtocolRegistry (25+ протоколов)

Полный список зарегистрированных протоколов:

**Transport (7):** Tor, Xray/V2Ray, I2P, WireGuard, Shadowsocks, Yggdrasil, cjdns

**Messaging (6):** SimpleX, Matrix, Tox, Session (Oxen), Briar, Nostr

**Storage (4):** IPFS, BitTorrent (DHT), Hypercore (Dat), ArchiveCloud

**Mesh (2):** libp2p, Kademlia DHT

**Application (1):** Matrix VoIP (calls)

### 7.7. ArchiveCloud (Децентрализованное облако)

P2P-хранилище на дисках пиров:
- SHA-256 контентно-адресуемые блоки (512 KB)
- Pin/Unpin с GC
- DHT-репликация (настраиваемый фактор)
- JSON-манифесты
- HTTP API сервер: `/stats`, `/blob/<hash>` (GET/PUT)

### 7.8. NodeMesh (P2P Mesh)

Децентрализованная mesh-сеть:
- SHA-256 идентификаторы узлов
- Kademlia-стиль DHT (FIND_NODE, GET_NEIGHBORS)
- Прямая отправка / широковещание
- Итеративный поиск маршрута
- Периодическое обнаружение + departure broadcast

## 8. БЕЗОПАСНОСТЬ И АУДИТ

### 8.1. SecurityAudit

Встроенный аудит безопасности. Запускается автоматически, проверяет:

| Проверка | Что ищет |
|----------|---------|
| Root-доступ | su бинарные файлы (9 путей) |
| Debug-режим | FLAG_DEBUGGABLE |
| Обфускация | ProGuard/R8 |
| Эмулятор | Build fingerprint, модель, производитель |
| БД шифрование | SQLCipher |
| Защита экрана | FLAG_SECURE |
| Буфер обмена | ClipboardGuard |

Результат: **AuditReport** с рекомендациями.

### 8.2. SecureStorage

Зашифрованное хранилище SecureSharedPreferences:

- PBKDF2 деривация ключа (10000 итераций)
- AES-256-GCM шифрование всех значений
- @Volatile + синхронизация для thread-safety

### 8.3. ScreenSecurityManager

- Устанавливает FLAG_SECURE на окна
- Блокирует скриншоты и запись экрана
- Активируется на всех экранах с конфиденциальными данными

### 8.4. DuressPinManager

- Генерация и верификация двух PIN-кодов
- PBKDF2WithHmacSHA256 вместо SHA-256
- MessageDigest.isEqual для constant-time сравнения
- Защита от timing-атак

### 8.5. TelegramReporter

Автоматическое уведомление о критических событиях в Telegram:
- Статус сборки
- Результаты аудита безопасности
- Crash-репорты
- Отчёты о работе сети

## 10. ФАЙЛЫ, МЕДИА И РЕЗЕРВНОЕ КОПИРОВАНИЕ

### 10.1. File Transfer (XFTP)

- Сквозное шифрование файлов
- Разбиение на блоки (chunking)
- Загрузка на XFTP-хосты
- Передача ссылки и ключей через E2E-чат

### 10.2. FileTransferManager

- Отслеживание прогресса передачи
- Поддержка паузы/возобновления
- Автоматический повтор при ошибках

### 10.3. FilePreviewScreen

Предпросмотр файлов:
- Изображения (JPEG, PNG, GIF, WebP)
- Видео (MP4)
- Документы (PDF)

### 10.4. Voice Messages

- Запись: VoiceRecorder → OpusEncoder (DCT сжатие)
- Плеер: VoiceMessagePlayer / StreamPlayer
- Шифрование AES-GCM перед передачей

### 10.5. RadioManager

- Фоновый аудио-сервер для радио-потоков
- RadioChannel — список станций
- RadioUIState — состояние плеера
- Одновременно работает как маскировка и как триггер доступа (Armageddon FM)

### 10.6. WebDavBackup

Резервное копирование на WebDAV-сервер:
- Бэкап БД, настроек, профилей
- HTTP-соединение с корректным закрытием (disconnect в finally)
- Поддержка резервных серверов

### 10.7. MessageExporter

## 12. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### 12.1. Почему не работает сеть? (Tor/V2Ray не запускаются)

Для работы сети требуются скомпилированные бинарные файлы:

```
app/src/main/assets/bin/
├── tor-arm64           # Tor для ARM64 (физические устройства)
├── tor-x86_64          # Tor для x86_64 (эмуляторы)
├── xray-arm64          # Xray core для ARM64
├── xray-x86_64         # Xray core для x86_64
├── simplex-arm64       # SimpleX CLI для ARM64
└── simplex-x86_64      # SimpleX CLI для x86_64
```

**Где скачать:**
- [Tor](https://github.com/nlitsme/android-tor-binary) — tor-android-binary
- [Xray](https://github.com/XTLS/Xray-core/releases) — v1.8.4+
- [SimpleX](https://github.com/simplex-chat/simplex-chat/releases) — v6.0.0+

Без бинарников приложение работает в оффлайн-режиме (игра с AI, чат с тестовым ботом, радио).

### 12.2. Как безопасно общаться?

1. Установите PIN-код в настройках
2. Активируйте **Radio Armageddon FM**
3. Включите **Tor + V2Ray** в настройках сети
4. Начните чат с контактом через QR-обмен
5. Все сообщения автоматически шифруются (Double Ratchet)

### 12.3. Как защититься от принудительного доступа?

1. Настройте **Duress PIN** (Settings → Privacy)
2. При вводе аварийного PIN открывается ложный калькулятор
3. Конфиденциальные данные недоступны

### 12.4. Как обновить приложение?

Соберите новый APK: `gradle assembleDebug` (в корне проекта)
APK: `app/build/outputs/apk/debug/app-debug.apk`

### 12.5. Как использовать Protocol Stack?

1. Откройте **Настройки → Protocol Stack**
2. На вкладке **Transport** настройте протоколы (Tor, V2Ray, Shadowsocks и т.д.)
3. Нажмите **«Start Full Node»** для запуска автопилота
4. Следите за статусами на вкладке **Diagnostics**
5. При необходимости настройте ArchiveCloud и NodeMesh на вкладках **Storage** и **Mesh**

### 12.6. Какая криптография используется?

- **Ключевой обмен:** X25519 ECDH (X3DH — 4 обмена Диффи-Хеллмана)
- **Шифрование сообщений:** XSalsa20-Poly1305 (NaCl crypto_box)
- **Рэтчет:** Double Ratchet (Signal Protocol)
- **Файлы:** AES-256-GCM
- **Хранилище:** PBKDF2 + AES-256-GCM
- **PIN:** PBKDF2WithHmacSHA256 (10000 итераций)
- **MAC:** constant-time сравнение (MessageDigest.isEqual)
